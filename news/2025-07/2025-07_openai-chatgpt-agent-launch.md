## 📰 OpenAI Unveils ChatGPT Agent: Transforming ChatGPT Into a Multitasking Digital Assistant

**Source:** Tom's Guide  
**Date:** 2025-07-17  
**URL:** [https://www.tomsguide.com/news/live/openai-july-17-announcement?utm_source=openai](https://www.tomsguide.com/news/live/openai-july-17-announcement?utm_source=openai)  
**Summary:** OpenAI introduced ChatGPT Agent, built on GPT-4o, enabling autonomous execution of multi-step tasks through an integrated virtual computer and tools such as browsers, code interpreters, and APIs for Gmail, Google Drive, and GitHub.

---

### 🔹 What Happened

OpenAI launched ChatGPT Agent, an AI enhancement that extends ChatGPT's capabilities by enabling it to perform complex, multi-step tasks autonomously. The agent operates via an integrated virtual computer environment, utilizing tools like a web browser, code interpreter, and connectors to popular APIs including Gmail, Google Drive, and GitHub. This allows users to delegate diverse tasks such as planning trips, preparing meals, conducting research, creating and exporting slide decks, and managing spreadsheets.

### 🔹 Why It Matters

The ChatGPT Agent marks a major shift from conversational AI to a versatile digital assistant capable of independently managing workflows. This can significantly enhance productivity by automating routine tasks and complex operations without constant user intervention. It's an important step towards AI that truly assists with everyday and professional needs, effectively blending research and actionable digital tasks.

### 🔹 Who's Involved

- OpenAI: Developer of ChatGPT Agent and GPT-4o model.

### 🔹 Technical Details

- **Base Model:** GPT-4o, a large multimodal model processing text and images, underpins ChatGPT Agent.
- **Agent Environment:** The agent features an integrated virtual computer enabling autonomous use of a browser, code execution environment, and direct API access to services like Gmail, Google Drive, and GitHub.
- **Capabilities:** Automates complex, multi-step tasks including research, business document generation, table and slide management, web interaction, and more.
- **Access:** Available to ChatGPT Pro, Plus, and Teams users initially, with Enterprise and Education users to be supported soon.
- **Safety Features:** Includes "watch mode" to pause tasks when not observed, disabled memory, restricted terminal access, and user confirmation prompts to mitigate risks.

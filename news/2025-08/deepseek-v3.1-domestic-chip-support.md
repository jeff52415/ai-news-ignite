# DeepSeek Releases V3.1 Model with Domestic Chip Support

**Source:** champaignmagazine.com  
**Date:** 2025-08-24

Chinese AI startup DeepSeek has unveiled an upgraded V3.1 model optimized for compatibility with domestic chips, aiming to reduce reliance on Silicon Valley technology. The model features a new hybrid inference structure allowing it to operate in reasoning and non-reasoning modes selectable via a "deep thinking" button on the company's app and web platform. The V3.1 also utilizes the UE8M0 FP8 precision format designed for next-generation domestic semiconductors, marking a strategic move aligned with China's push for technological self-sufficiency amid external trade restrictions. API pricing adjustments are scheduled from September 6, 2025.

## Technical Details

- Model: DeepSeek-V3.1
- Precision Format: UE8M0 FP8
- Inference Structure: Hybrid (reasoning and non-reasoning modes)
- Interface Feature: "Deep thinking" toggle button
- Target Platform: Domestic Chinese chips
- API Cost Adjustment Date: 2025-09-06

## Significance

DeepSeek's release challenges Silicon Valley dominance in AI hardware compatibility and potentially reshapes global AI technology development by fostering cost-effective, domestic chip-supported AI models.

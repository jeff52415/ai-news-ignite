# 📰 OpenAI Releases ChatGPT Atlas Browser

**Source:** OpenAI  
**Date:** 2025-10-21  
**URL:** [https://openai.com/index/introducing-chatgpt-atlas/](https://openai.com/index/introducing-chatgpt-atlas/)

OpenAI has launched ChatGPT Atlas, an AI-powered Chromium-based web browser featuring webpage summarization, inline text editing, browser memories for context retention, and an optional agent mode for automating tasks. Initially available on macOS, versions for Windows, iOS, and Android are forthcoming.

## What Happened
OpenAI unveiled ChatGPT Atlas, an AI-integrated web browser designed to enhance user experience by incorporating ChatGPT's capabilities directly into the browsing environment.

## Why It Matters
This launch signifies OpenAI's strategic move into the web browser market, aiming to challenge established browsers like Google Chrome by offering AI-driven features that streamline tasks and improve productivity.

## Who's Involved
- OpenAI: Developer of ChatGPT Atlas
- Sam Altman: CEO of OpenAI

## Technical Details
- Engine: Chromium-based
- Features:
  - ChatGPT Sidebar for real-time assistance
  - Browser Memories for context retention
  - Agent Mode for task automation, available for Plus, Pro, and Business users
